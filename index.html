Process

How I work with data.

The same five steps, whether it's a quick analysis or a full ML system.

Frame the question

Agree on the decision the analysis must support, the metric that defines success, and what "no answer" looks like.

Collect, validate & clean

Profile every column, quarantine bad rows instead of silently fixing them, and keep lineage so each number traces back to its source. pandas SQL

Explore

Distributions, outliers, correlations and segment cuts, with statistical tests before any claim. EDA scipy

Model & evaluate

Start from a simple baseline, then validate properly (cross-validation, holdout, calibration) and explain what drives predictions. scikit-learn SHAP

Communicate & ship

Dashboards, written findings, or an API. Whatever gets the insight used, with its limitations stated plainly. Streamlit FastAPI
